教室で使えるかもしれないもの作り

「なぞれた」で終わらせない。書き順まで見てくれる漢字学習アプリ「マイ漢字タウン」

2026/08/23 現在

マイ漢字タウン を開く コードを見る

🏫 はじめに

漢字の丸付けをしていて、こんなふうに迷ったことはありませんか。

形はきれいに書けている。でも、書いているところを見ていたら、たぶん書き順が違っていた。ノートに残るのは書き上がった字だけなので、あとから見ても、その子がどの順番で書いたのかは分かりません。同じように、はねるところで止めてしまった、突き抜けるところで止めてしまった、というつまずきも、答案の上ではほとんど見分けがつきません。三十数人ぶんのノートを前にして、そこまで一人ひとり確かめるのは、正直むずかしいと思います。

以前この連載で「マイ漢字タウン」というアプリを紹介しました。漢字を覚えると自分の町が育っていく、小学生向けの漢字学習アプリです。あれから半年ほどのあいだに、いちばん大事なところを作り直しました。書けたかどうかを判定する仕組みを、根っこから組み直したのです。

いまのマイ漢字タウンは、子どもが書いた線を一画ずつ見て、字の形、書き順、とめ・はね・はらい、点画の交わりかたを別々に評価します。そして「何点だったか」だけでなく「なぜその点数なのか」を、子ども自身に見せます。

https://kanji-town.giga-school.com/

アカウントの登録は要りません。URLを開けば、その場で始められます。学習の記録は、その端末の中だけに残ります。

📱 このアプリでできること

小学校で習う教育漢字1026字を、すべて収めています。1年生の80字から6年生の181字まで、学年配当のとおりに並んでいます。

一つの漢字は、音読、書き順を見る、なぞる、テスト、という4つの段階で進みます。この流れ自体は前回と同じですが、中身はどこも入れかわりました。

最初は音読です。その漢字を使った例文が出てきます。例文はアプリ全体で2000をこえる数を用意しました。読みかたと意味を、字を書く前に頭に入れておくためのステップです。

つぎに書き順を見ます。ここで使っている字の形は、KanjiVGという書き順のデータをもとにしています。以前は、音読の画面やフラッシュカードでは画面の書体をそのまま出し、なぞり書きや書き順ではKanjiVGを使っていたので、同じ漢字なのに画面によって形が少し違って見えていました。いまは学習中の漢字をすべて同じ筆画データでそろえています。読むときに見た字、なぞる手本、採点に使う手本が、すべて同じ形です。

そのあとが、なぞり書きです。ここも大きく変えました。まず、書くマスそのものを画面いっぱいまで大きくしました。以前は端末によってマスが小さくなり、細かい字が書けないことがありました。いまは画面の高さに合わせて、そのときいちばん大きく取れる大きさに自動で変わります。指でもタッチペンでも、無理なく書けると思います。

回数を重ねると、手本が少しずつ引いていきます。1回目と2回目は線に吸いつく「なぞり書き」、3回目から5回目は手本がうすく残る「手書き」、6回目からは手本のない「空書き」です。同じ字を書きながら、支えだけが減っていく作りにしました。急に一人にしないための段階です。

最後がテストです。手本のないマスに、その漢字を書きます。書き終えると採点され、こたえと並べて見せてくれます。

覚えた漢字は、町の住人としてマップに増えていきます。学習を続けるとマップが広がり、集めた素材で建物を作れるようになります。忘れそうなタイミングになると町にお化けが出てきて、それが復習の合図になります。この部分の考えかたは前回から変えていません。反復そのものを、続けたくなる形に置きかえたい、という作りです。

✍️ 「なぜ その点数か」がわかる採点

今回いちばん時間をかけたのが、ここです。

以前の判定は、正直なところ、書きはじめと書きおわりの位置しか見ていませんでした。両端さえ合っていれば、その間の形がどれだけ崩れていても満点が出ます。とめ・はね・はらいは点数に入っておらず、書き順も、似た形の画が並ぶ字では正しく書いても誤って判定されることがありました。これでは、いちばん直したいところが直せません。

いまは100点を6つに分けて配点しています。字の形が30点、書き順が25点、とめ・はね・はらいが15点、点画の交わりかたが10点、書きはじめの位置が10点、書きおわりの位置が10点です。合格は70点にしました。

そして、その内訳を子どもに見せます。マイドリルのテストで採点されたカードをタップすると、自分の書いた字と手本が番号つきで並び、どの項目で何点だったかが棒グラフで出てきます。

この画面は、わざと書き順を入れかえて書いてみたときのものです。字の形は30点満点、とめ・はね・はらいも満点、点画の交わりも正しい。それでも合計は69点で不合格になります。書き順に誤りがあるときは、69点より上には行かないようにしてあるからです。

なぜそんな上限を設けたのか、少し説明させてください。たとえば「三」という字は、下から書いても見た目はまったく同じになります。形だけを見る採点だと、これは満点です。上限を作らないと、書き順の誤りが点数にまったく表れません。それでは書き順を身につける役に立たないので、形が完璧でも合格させない、という線を引きました。ただし0点にはしません。どこがどう違ったのかを、点数と講評に残しています。全部だめだと言われると、次を書く気持ちがなくなってしまうからです。

点画の交わりかたも、測りかたを変えました。「土」のようにT字に接するだけの画と、「牛」のように突き抜ける画は、区別しないといけません。以前は線が何回交差したかを数えていたのですが、この数えかたには弱点があって、ゆっくり書くと交差の判定が出やすく、速く書くと出にくい、という書く速さ次第の判定になっていました。いまは「どれだけ突き抜けたか」の長さで見ています。速く書いても、ゆっくり書いても、同じ結果になります。

とめ・はね・はらいについては、ひとつ決めごとをしました。正解が分からないときは褒めない、というものです。以前は子どもの書いた終筆をそのまま読み取って「きれいなハネ！」と返していたのですが、これだと、とめるべきところではねても褒めてしまいます。誤りをこちらから強化していたことになります。いまは手本の側に筆画の種類の情報があるときだけ判定し、分からないときは中立の言葉を返します。

また、この項目の配点はあえて15点と控えめにして、外れても半分の点は残るようにしています。文部科学省の「常用漢字表の字体・字形に関する指針」が、終筆の細かい部分にはある程度の幅を認めているためです。細部を厳しくしすぎて、書くこと自体を怖がらせたくありませんでした。

採点の仕組みは、通常の学習でも、マイドリルのテストでも、ボスバトルでも、まったく同じものを使っています。画面によって基準が変わることはありません。

🎤 声に出して読んだかを確かめる音読チャレンジ

もうひとつ増えたのが、音読チャレンジです。

音読の画面は、これまで「声にだそう！」と表示するだけで、タップ1回で次へ進めました。声を出さなくても通り抜けられたわけです。声に出して読むことには、黙読より記憶に残りやすいという裏づけがあるので、実際に声を出したことを確かめる仕組みを入れました。

マイクのボタンを押すと、アプリが声を聞きとります。しっかり声が出ていればクリアで、ボーナスの経験値がもらえます。

ここは先生方がいちばん気になるところだと思うので、先に書いておきます。声は録音していません。保存もしていませんし、どこにも送っていません。アプリが見ているのは「いま音が出ているかどうか」の大きさだけで、その数値に変えた時点で、音そのものは消えています。判定が終わるとマイクはすぐに手放すので、端末の録音中の表示も消えます。

読みかたが合っているかどうかまでは判定していません。声を出して読んだ、という行動そのものを支えるための機能です。クラウドの音声認識を使えば読みの正誤まで見られますが、それだと声が外のサーバーへ送られてしまいます。このアプリは記録を外に出さない作りで通しているので、そちらは採りませんでした。

しきい値は、その場の静かさに合わせて自動で決まります。静かな教室で敏感になりすぎず、ざわついた教室でも叫ばずに済むようにしてあります。咳やタップの音のような短い音は、声として数えません。

お手本の読み上げもつけました。こちらも端末の中に入っている音声だけを使っています。正しい読みを聞いてから自分で声に出す、という流れを作りたかったからです。

マイクが使えない端末や、許可されていない環境では、チャレンジのカードが案内表示に変わります。学習はそのまま最後まで進められます。ボーナスの経験値がつかないだけです。設定から機能ごと切ることもできます。

✨ 導入のメリット

三つのいいことが期待できます。

一つ目は、先生が見えなかったところが見えるようになることです。ノートに残るのは書き上がった字だけですが、このアプリは書いている途中の運びを見ています。字の形はいいのに書き順でつまずいている子、はらうところで止めてしまう子を、答案からではなく、その場で見分けられます。子ども自身が「なぜ69点なのか」を画面で確かめられるので、先生が一人ずつ説明して回らなくても、直すべきところが本人に届きます。

二つ目は、丸付けの時間が減ることです。字形と書き順の細かい判定はアプリが引き受けます。そのぶん先生は、「この字、はねが力強くなったね」「住人がこんなに増えたね」といった、数字にならない伸びを言葉にすることに時間を使えるのではないかと思います。丸付けに追われる時間が、子どもと話す時間に変わっていくのが理想です。

三つ目は、学び方の選択肢が増えることです。今日は鉛筆でノートに向かいたい、今日は集中が切れそうだからアプリで町を育てながら頑張る。そんなふうに、その日のコンディションで手段を選べるようになります。ノートにはノートの良さがあり、これを置きかえるつもりはありません。ただ、選べる状態を作っておくことで、自分に合った学び方を自分で探す土台ができていくのだと思います。

🛠️ 【管理者向け】導入手順

情報担当の先生に確認されそうなことを、先にまとめておきます。

導入の作業は、URLを子どもたちに伝えるだけです。インストールも、アカウントの登録も要りません。

https://kanji-town.giga-school.com/

個人情報については、氏名も出席番号もメールアドレスも、入力する場所自体がありません。学習の記録は児童が使った端末の中だけに保存され、外へ送信されません。以前はクラウドに記録を預ける仕組みを作っていたのですが、これは取りやめました。記録を外に置かなければ、外に漏れる心配もなくなるからです。音読チャレンジの声も、録音・保存・送信を一切しません。マイドリルの受け渡しも、サーバーを通しません。

校内のフィルタリングで許可が必要になりそうなアドレスは二つあります。一つめは cdn.jsdelivr.net で、書き順の手本データを取り込むところです。ここが止まっていると、うすい手本が表示されません。一度取り込めば端末に残るので、次からはつながっていなくても表示されます。二つめは fonts.googleapis.com で、画面の書体です。止まっていても端末の書体で代わりに表示されるので、学習に支障はありません。

インターネットは、最初の1回だけつながっていれば大丈夫です。ホーム画面に追加しておくと、アプリのように1タップで開けるようになり、つながっていない場所でも起動します。学習の記録が消えにくくなるので、続けて使う場合は追加をおすすめします。

iPadとiPhoneについては、ひとつだけ気をつけていただきたい点があります。Safariの仕様で、7日間まったく開かないと保存した記録が自動で消えることがあります。ホーム画面に追加しておくと起きにくくなりますが、長期休業をはさむときは、休みに入る前に記録の書き出しをしておくと安心です。設定の中に、記録をファイルに書き出す機能と、別の端末で読み込む機能があります。学年が上がって端末を入れ替えるときも、この二つで引き継げます。

うまく動かないときのために、端末の状態と最近のエラーを表示する画面も用意しました。設定の下のほうにあります。この画面を見せていただければ、原因が分かりやすくなります。ここにも個人情報は含まれません。

先生向けの手引きは MANUAL.md として別に用意しました。専門用語を使わずに書いてあります。

📖 【利用者向け】使い方のガイド

はじめて使う日

  1. 児童の端末で上のURLを開きます。
  2. 最初に案内が出ます。「つぎへ」で読み進めるか、時間がなければ「スキップする」で飛ばせます。
  3. 学年を選びます。
  4. 赤い「きょうの5字」を押すと、その日の学習が始まります。

1回の学習はおよそ10分です。1字ごとに、音読、書き順を見る、なぞる、テストの順に進みます。

先生がドリルを配る

覚えさせたい漢字だけを集めたオリジナルのドリルを作って、子どもたちに配れます。今週習った5字だけを集める、一学期に間違いが多かった字を集める、といった使いかたを想定しています。学年をまたいで選べます。

配りかたは2通りあります。今回の更新で増えたのが、リンクで配る方法です。

  1. マイドリルの一覧で、配りたいドリルの「リンク」ボタンを押します。
  2. 「Google Classroom で共有する」を押すか、URLをコピーします。
  3. コピーしたURLは、Classroomの課題や資料、学級だよりに貼りつけられます。
  4. 子どもはそのリンクを開くだけで受け取れます。

この方法だと、同じ教室にいなくても配れます。家庭学習にも使えますし、学級閉鎖のときにも届きます。アカウントの連携も、APIキーの設定も要りません。Classroomの共有画面を開くだけの作りにしてあるからです。

気をつけていただきたいのは、配ったあとにドリルを直しても、配り済みのリンクの中身は変わらないことです。直したら、リンクを配りなおしてください。それと、漢字を入れすぎるとURLが長くなりすぎます。長すぎる場合は画面が知らせてくれるので、そのときはドリルを分けてください。

もう1つは、4けたの数字で送る方法です。同じ教室にある端末どうしを直接つなぎます。先生の端末に4けたの数字とQRコードが出るので、子どもはそれを入れるか読み取るだけです。電子黒板に映すときは「大きく表示」を押すと文字が1.5倍になり、教室の後ろの席からも読めます。

ドリルでテストする

  1. マイドリルの一覧で「テスト」を押します。
  2. 何問出すかを選びます。
  3. 例文の中の「◯」のところに、その漢字を書きます。
  4. 「答える」を押すと、次の問題に進みます。
  5. 全部書き終えると、まとめて採点されて結果が出ます。

一問ごとに止まらないので、テストらしい緊張感のまま最後まで走り抜けられます。結果の画面では、点数のついたカードが並びます。カードを押すと、さきほどの採点の内訳が開きます。

まちがえた字だけを選んで練習しなおせるので、できた字をもう一度やる時間は要りません。

📝 まとめ

漢字の練習は、どうしても反復から逃げられません。逃げられないからこそ、その時間の質を上げたいと思って作り直しました。

なぞれたことと、書けるようになったことは、同じではありません。形が合っていても、書き順が身についていなければ、画数の多い字に進んだときに必ずつまずきます。そこを見分けて、理由まで本人に返す。今回の更新は、そのためのものです。

そして、細かい判定をアプリが引き受けるぶん、先生の手には時間が残ります。その時間で、点数には出てこない伸びを見つけて、言葉にしてあげてほしいと思っています。ICTを使うことで生まれる、子どもと向き合う時間のゆとり。そのゆとりこそが、教育の質を高めるのだと私は信じています。

これまでのノートやドリルも大切にしながら、三つ目の選択肢としてこのツールを添えてみてください。今日はどっちで頑張る、という問いかけが、子どもたちが自分で学びを動かしはじめる一歩になるはずです。

もし授業や家庭学習で使ってみた感想があれば、コメントなどで教えていただけると嬉しいです。現場の先生方の声が、この町をより良くしていく一番の材料になります。

一歩踏み出そうとする先生を、私はいつでも全力で応援しています。
