Typa（タイパ）で できること

Typa は、キーボードで 文字を 打うつ れんしゅうを する アプリです。ここでは、なにが できるのかと、はじめる まえに 用意よういする ものを せつめいします。

Typa は どんな アプリ？

ブラウザで ひらくだけで つかえる、タイピングの れんしゅう アプリです。アプリを ダウンロードしたり、名前や あいことばを つくったりする ひつようは ありません。

ひらいた 画面がめんが、そのまま 打うつ 画面がめんです。「はじめる」の ボタンは ありません。キーを たたけば、その ばで れんしゅうが はじまります。なにを 打うつかは アプリが きめて 出すので、えらばなくて だいじょうぶです。

中に 入って いるのは、5つの コースと 32の ステージです。ゆびの ばしょを おぼえる ところから はじめて、ローマ字、ことば、文、そして コピーや はりつけの ショートカットまで すすみます。そのほかに、時間の 中で どれだけ 打うてるかを ためす「チャレンジ」と、まちがえやすい キーだけを あつめた「にがて とっくん」が あります。

打うった きろくは、じぶんの 端末たんまつの 中にだけ のこります。名前や 出席しゅっせきばんごうを 入れる ところは ありません。インターネットに おくる ことも ありません。

つかう人と、用意よういする もの

つかうのは、キーボードを れんしゅうする みなさんです。先生だけが つかう ところも すこし ありますが、そこには「先生むけ」「先生へ」と 書いて あります。

はじめる まえに、つぎの ものが 手もとに あるか たしかめて ください。

  1. キーボードの ついた Chromebook か パソコン。タブレットでも つかえますが、キーボードを つないで ください。
  2. インターネットに つながって いる こと。さいしょの 1回だけ ひつようです。
  3. ひらく ところ（アドレス）… https://typa.giga-school.com/

ID や パスワードは いりません。アカウントを つくる ひつようも ありません。

はじめて ひらく ときに する こと（さいしょの 1回だけ）

さいしょの 1回だけ、やって おくと いい ことが 3つ あります。2つめは、キーを おしても すすまない ときの いちばん おおい げんいんです。

ブラウザで アドレスを ひらく

Chrome などの ブラウザを ひらいて、上の アドレスの ところに つぎの ように 打うって、エンターキーを おして ください。

https://typa.giga-school.com/

すぐに 打うつ 画面がめんが 出ます。「はじめる」を おす ひつようは ありません。

さいしょの 1回は、かならず インターネットに つながった ところで ひらいて ください。その ときに アプリ ぜんぶが 端末たんまつの 中に 入ります。つぎからは、つながって いなくても つかえます。

ローマ字が 打うてる ように する（かな入力を 切る）

日本語入力（かな入力）に なって いると、キーを おしても 画面がめんが すすみません。かなが 出て きたら、つぎの どちらかの キーを 1回 おして ください。

  1. かな英数えいすうキー … キーボードの「1」の すぐ 左に あります。
  2. 英数えいすうキー … スペースキーの すぐ 左に あります。

かな入力の ままで 打うつと、画面がめんに つぎの おしらせが 出ます。

Chromebook や タブレットに アプリとして 入れて おく

ホーム画面がめんに 入れて おくと、ブラウザの バーが 消きえて 画面がめんが 広く なり、つぎから すぐ ひらけます。入れ かたは 端末たんまつに よって ちがいます。

  1. Chromebook・Windows（Chrome / Edge）… アドレスの ところの 右はしに 出る インストールの しるしを おします。せってい →「データ」の 中に ある「ホーム画面がめんに 入れる」から でも できます。
  2. iPad・iPhone … Safari で ひらいて、共有きょうゆうボタン（□に ↑ の しるし）→「ホーム画面がめんに追加ついか」→「追加ついか」と おします。iPad には Chrome のような インストールの ボタンが ないので、かならず Safari で ひらいて ください。
  3. Android … メニュー →「アプリをインストール」または「ホーム画面がめんに追加ついか」を おします。

【！】おぼえて おいて ほしい こと

  • 入れなくても、ブラウザの ままで ぜんぶ つかえます。
  • 「ホーム画面がめんに 入れる」の ボタンが 出ない ときは、もう 入って いるか、その ブラウザが たいおうして いません。
  • 入れても、きろくは その 端末たんまつの 中に のこった ままです。べつの 端末たんまつには うつりません。

うつ がめんの みかた

ひらいた ときに 出る「うつ」の 画面がめんには、上・まん中・下の 3つの ばしょが あります。どこに 何が あるかを おぼえて おくと、まよわなく なります。

いちばん 上の バーに ある もの

いちばん 上には、いま やって いる コースと ステージの 名前、それに すすみぐあいの バーが 出ます。

ステージの 名前の よこに「かえる」と 書いて あります。ここを おすと、ステージを えらぶ 画面がめんに いけます。「これじゃ ない」と 思った ときに つかいます。

右はしの「ひとまわりまで あと ◯」は、あと 何もん 打うつと ひとまわりに なるかを あらわして います。0に なると ★が つきます。

まん中の お題だいと、その 下の しらせ

まん中の 大きな 白い ところが お題だいです。いま 打うつ ところに 下線が つきます。

お題だいの 下には「つぎは ◯ を ◯ゆびで」と 出ます。その 右に「はやさ」「正かくさ」「ミス」「れんぞく」の 4つの 数字が ならびます。はやさは 1びょうに 何回 打うてて いるか、正かくさは まちがえずに 打うてた わりあいです。

下の バーに ある 5つの ボタン

画面がめんの いちばん 下に、いつも 5つの ボタンが ならんで います。

  1. もどる … 1つ 前の 画面がめんに もどります。画面がめんの はしから 中へ スワイプしても、Alt と ← を おしても 同じです。
  2. うつ … 打うつ 画面がめんに いきます。つづきから はじまります。
  3. えらぶ … コース・チャレンジ・にがて とっくんを えらぶ 画面がめんです。
  4. きろく … これまでの あゆみを 見る 画面がめんです。
  5. せってい … ヒントの つよさや 見た目を かえる 画面がめんです。

【！】おぼえて おいて ほしい こと

  • どの 画面がめんでも スペースキーを おすと、打うつ 画面がめんに もどれます。ボタンを さがさなくて だいじょうぶです。
  • ただし、文字を 書く ところや スイッチの 上に カーソルが ある ときは、スペースキーは その ばの はたらきに なります。

キーを 打うつ ときの きまり

打うちかたの きまりは 3つ だけです。ここが 分かれば、あとは ずっと 同じ やりかたで すすめます。

光って いる キーを、同じ 色の ゆびで 押おす

画面がめんの 下に、キーボードの 絵と 両手りょうての 絵が 出て います。つぎに 打うつ キーが 光るので、その キーを おします。

お題だいの 下の ことばも、同じ ことを 教えて くれます。

シフトが いる キーの ときは、打うつ 手と 反対はんたいの 小ゆびも いっしょに 光ります。かた手で おさない ためです。

ホームポジションは、左手を F、右手を J に おく ばしょです。この 2つの キーには でっぱりが あるので、見なくても さわれば 分かります。

まちがえると すすまない

まちがえた キーを おしても、お題だいは 先へ すすみません。あわてずに、正しい キーを さがして ください。

まちがえても きろくは 消きえません。うしろに もどる ことも ありません。

同じ お題だいで 4回 まちがえたら「とばす」

同じ お題だいで 4回 まちがえると、画面がめんの 下に「この お題だいを とばす」と いう ボタンが 出ます。

1つの キーの ところで ずっと 手が 止まらない ように する ための ボタンです。おすと、つぎの お題だいに すすみます。とばした ことは きろくに のこるので、あとで「にがて とっくん」に 出て きます。

ひとまわりと ★の つきかた

ステージには「おわり」が ありません。かわりに「ひとまわり」と いう 区切くぎりが あって、そこで ★が つきます。

ひとまわりって なに？

ステージに 入って いる お題だいの 数だけ 打うつと、1しゅう したと いう ことで「ひとまわり」に なります。ひとまわりする たびに ★が つきます。

とちゅうで やめても、打うった ぶんは 消きえません。3もんだけ 打うって やめても すすみに たまり、つぎに ひらくと その つづきから 出ます。だから 10びょうでも、何十分でも、同じ ように つかえます。

★は、はやさでは なく 正かくさで つきます。

  1. ★3つ … 正かくさ 98% いじょう。または まちがいが 1回まで。
  2. ★2つ … 正かくさ 92% いじょう。または まちがいが 2回まで。
  3. ★1つ … 正かくさ 80% いじょう。または まちがいが 3回まで。

一度いちど ついた ★は、つぎに うまく いかなくても 下がりません。

★3つに なると、その ばで つぎの ステージへ

ひとまわりして ★3つに なると、その ばで つぎの ステージに 入れかわります。「おわりました」の 画面がめんは はさみません。お題だいと ステージの 名前が かわって、そのまま 打うちつづけられます。

入れかわるのは 1もん 打うち終おえた ところなので、打うちかけの ことばが とり上げられる ことは ありません。行き先は、まだ ★3つに なって いない いちばん 近い ステージです。

【！】おぼえて おいて ほしい こと

  • ぜんぶの ステージが ★3つに なると、それいじょうは 入れかわりません。
  • けっか画面がめんの「もう1かい」や、じぶんで えらんで 入った ときは 入れかわりません。じぶんで きめた ことを とり上げない ためです。
  • チャレンジと にがて とっくんでは ★は つきません。

れんしゅうを やめて、けっかを 見る

打うつのを おわりに する ときは「やめる」を おします。おした ところまでの きろくが のこり、けっかの 画面がめんが 出ます。

けっかの がめんに 出る 数字

画面がめんの いちばん 下に ある「やめる」を おすと、けっかの 画面がめんに かわります。

  1. はやさ … 1びょうに 何回 打うてたか（打だ／びょう）です。
  2. 正かくさ … まちがえずに 打うてた わりあい（%）です。
  3. 正しく 打うてた 数 … その 回に 正しく おした キーの 数です。
  4. ミス … まちがえた 回数です。
  5. れんぞく … つづけて 正しく 打うてた いちばん 長い 数です。

下の ほうには、ふえた けいけんち、もらった バッジ、そして「つぎは これを やろう」が 出ます。いちばん 下の 3つの ボタンで、もう1かい やるか、つぎの ステージへ いくか、コースに もどるかを えらべます。

「くわしく 見る」で どこで 手が とまったかを 見る

けっかの 画面がめんの まん中あたりに ある「くわしく 見る」を おすと、たたんで あった ところが ひらきます。

グラフの よこは 打うった じゅんばん、たては その 1打だに かかった 時間です。高く なって いる ところが、手が 止まった ところです。まちがえた ところは 色と 形の りょうほうで 分かるように なって います。

「えらぶ」から やる ことを きめる

下の バーの「えらぶ」を おすと、ほかの ことを やりたい ときの 入口が ならびます。

えらぶ がめんに ならぶ もの

えらぶ の 画面がめんは、左と 右で 役やくわりが 分かれて います。左には いま やって いる ところ、右には ほかの れんしゅうへの 入口が ならびます。

  1. コースから えらぶ … 5つの コースと 32の ステージから えらびます。
  2. チャレンジ … 時間の 中で どれだけ 打うてるかを ためします。
  3. にがて とっくん … まちがえやすい キーだけを あつめて 打うちます。
  4. きょうの ようす・きろく …「きろく」の 画面がめんに いきます。

ふくしゅうの 日が 来て いる ときと、とちゅうの ステージが ある ときは、その カードが いちばん 上に 出ます。

コースから ステージを えらぶ

「コースから えらぶ」を おすと、5つの コースが ならびます。

  1. ゆびの ばしょを おぼえる … ホームポジションから 上の だん・下の だん・すうじ・きごうまで。8ステージ。
  2. ローマ字を おぼえる … あ行から わ行、てんてん、ん、ちいさい つ、ちいさい や ゆ よまで。11ステージ。
  3. ことばを 打うつ … みのまわり・がっこう・まなび・コンピュータ・地名の ことば。5ステージ。
  4. 文を 打うつ … あいさつ・にっき・ふり返かえり・ながい 文。4ステージ。
  5. ショートカットを つかう … コピー・はりつけ・もとにもどす・えらぶ・べんりな キー。4ステージ。

コースを おすと、その 中の ステージが ならびます。

打うちたい ステージを おすと、その ばで 打うつ 画面がめんに かわります。まだ やって いない ステージも えらべます。

きょうの ふくしゅうを する

一度いちど できた ところも、日が たつと わすれます。Typa は、ちょうど わすれかけた ころに もう一度いちど 出して くれます。

ふくしゅうは ひらいた ときに いちばん さきに 出る

ふくしゅうの 日が 来て いる ステージが ある ときは、アプリを ひらいた ところに その ステージが 出ます。「えらぶ」の 画面がめんにも、いちばん 上に 出ます。

ふくしゅうを さきに 出すのは、日づけで きまるのが ふくしゅうだけ だからです。とちゅうの ステージは、あした つづきを 打うっても 同じ 結果けっかに なります。だから、その日に やらないと 損そんを する ものから 先に 出す ように して あります。

ふくしゅうの ステージは、ふつうの ステージと まったく 同じ ように 打うちます。★も つきますし、けいけんちも たまります。ちがうのは、出て くる じゅんばんだけです。

ふくしゅうが 2つ いじょう たまって いる ときは、2つ目からは「えらぶ」の 画面がめんに ならびます。いそいで いる ときは、1つ だけ やって おわりにしても かまいません。のこりは また あした 出ます。

間を のばしながら 出る しくみ

★2つ いじょうで ひとまわり できると、つぎに 出る 日が だんだん 先に なって いきます。

  1. 1回目の あと … 1日 あと
  2. 2回目の あと … 3日 あと
  3. 3回目の あと … 7日 あと
  4. 4回目の あと … 14日 あと
  5. 5回目の あと … 30日 あと

ひとまわりの ★が 1つ いがいの ときは、はこが 1に もどって、また あした 出ます。おぼえて いる ものほど 間が あくので、少ない 回数で わすれずに いられます。

しばらく Typa を ひらかなかった ときは、7日 いじょう さわって いない ステージも ふくしゅうに よばれます。ひさしぶりに ひらくと たくさん 出て くるのは その ためです。

【！】おぼえて おいて ほしい こと

  • ふくしゅうの ステージを とばしても、きろくは 消きえません。つぎに ひらいた ときに また 出ます。
  • ふくしゅうを して いる あいだも、★3つに なれば つぎの ステージに 入れかわります。
  • どの ステージが ふくしゅうに 出るかは アプリが きめます。じぶんで えらぶ ことは できません。

にがて とっくんで、まちがえた キーだけ 打うつ

まちがえやすい キーを 見つけて、その キーだけを あつめた お題だいを その ばで つくります。お題だいは さいだい 16もんで、90びょうくらいで おわります。

つかえるように なる とき

にがて とっくんは、はじめから つかえる わけでは ありません。まちがえた キーが 2つ たまるか、とりちがえが 1くみ たまると えらべるように なります。

すこし 打うてば すぐに たまるので、まずは ふつうに れんしゅうして ください。

にがて とっくんを はじめる

「にがて とっくん」を おすと、すぐに 打うつ 画面がめんに かわります。

打うち終おわると、けっかの 画面がめんに かわります。

【！】おぼえて おいて ほしい こと

  • にがて とっくんに ★は つきません。ステージの ★は かわりません。
  • 出て くる お題だいは、その ときの きろくから 毎回 つくられます。同じ ものが 出るとは かぎりません。
  • 5回 やると「にがて つぶし」の バッジが もらえます。

チャレンジで、じかんの 中で どれだけ 打うてるか ためす

きめられた 時間の 中で、どれだけ 正しく 打うてるかを ためす あそびです。ステージの ★には えいきょうしません。

じかんと 打うつ ものを えらぶ

「えらぶ」→「チャレンジ」と おすと、えらぶ 画面がめんが 出ます。

  1. じかん … 30びょう・60びょう・120びょうの 3つから えらびます。
  2. なにを 打うつ？ … ことば・文・アルファベットの 3つから えらびます。
  3. さいこう記録きろく … その くみあわせで いちばん よかった きろくが 出ます。

えらんだら、いちばん 下の「はじめる」を おします。

チャレンジを はじめる

はじめると、上の バーが 時間の のこりに かわります。

正しく 打うてた 数が スコアです。まちがえると すすまないので、あわてず ていねいに 打うつ ほうが たくさん 打うてます。

時間が 来ると、その ばで けっかの 画面がめんに かわります。

ショートカットの ステージで、コピーと はりつけを おぼえる

ショートカットの コースだけは、ほかと 打うちかたが ちがいます。キーを 打うつのでは なく、じっさいに 文を コピーしたり はりつけたり します。

ショートカットの ステージの みかた

「コースから えらぶ」→「ショートカットを つかう」を おすと、4つの ステージが ならびます。

ステージを おすと、上に やる ことが 1つ 出て、下に「もとの文」と「じぶんの文」と いう 2つの 入力らんが 出ます。

じっさいに コピーして はりつける

たとえば「コピーと はりつけ」の ステージでは、つぎの じゅんばんで やります。

  1. 「もとの文」の 中を 1回 クリック（タップ）します。文字を 打うつ ところを えらんで いないと、キーが とどきません。
  2. Ctrl を おしながら A を おします。もとの文が ぜんぶ えらばれます。
  3. Ctrl を おしながら C を おします。えらんだ 文が コピーされます。
  4. 「じぶんの文」の 中を クリックしてから、Ctrl を おしながら V を おします。コピーした 文が はりつけられます。
  5. もう1かい Ctrl と V を おします。コピーは なんども つかえるので、2つ ならびます。

できると、その ばで「できました！」と 出て、つぎの やる ことに かわります。

4つ ぜんぶ できると、けっかの 画面がめんに かわります。

【！】おぼえて おいて ほしい こと

  • どうしても できない ときは、下の「この 課題かだいは とばす」を おせます。
  • Ctrl の かわりに Chromebook の けんさくキーを つかう ものも あります。画面がめんに 書いて あるので、その とおりに おして ください。
  • ここで おぼえた キーは、ほかの アプリでも そのまま つかえます。

ぜんぶ ★3つに なった あと（だん）

★は 正かくさで つくので、ぜんぶ ★3つに なった 人には それいじょう のびが 見えません。その さきの 目じるしが「だん」です。

だんは どうすると 上がるか

だんは、ヒントを 1つ 消けした ままで はやさの めやすに とどくと 上がります。1だんから 3だんまで あります。

  1. 1だん … ヒントを「ゆびの 色だけ」いじょうに して、2.0 打だ／びょう。
  2. 2だん … ヒントを「ばしょだけ」いじょうに して、3.0 打だ／びょう。
  3. 3だん … ヒントを「なにも 出ない」いじょうに して、4.0 打だ／びょう。

どれも、ひとまわりの ★が 3つの ときだけ 上がります。まちがえても はやければ よい、に ならない ように する ためです。★と 同じで、一度いちど 上がった だんは 下がりません。

そのさきの すすみかた

ぜんぶの ステージが ★3つに なると、アプリの 出しかたが かわります。「えらぶ」の 画面がめんと ひらいた ときの お題だいが「そのさき」に かわり、だんの いちばん ひくい ステージから 出るように なります。同じ ステージばかりに ならない ように、長く さわって いない ものから えらばれます。

この ときから、打うつ 画面がめんに はやさの めやすが 出ます。それまで 出さないのは、まだ ★を あつめて いる とちゅうの 人が、正かくさより はやさを おいかけて しまわない ように する ためです。じゅんばんは いつも、正かくさが 先で、はやさは その 上です。

だんの カードは、けっかの 画面がめんで つぎの だんまで 何が 足りないかも 教えて くれます。ヒントを へらすのが 足りないのか、はやさが 足りないのか、それとも ひとまわりの ★が 3つに なって いないのかが、その ばで 分かります。

3だんまで 上がった ステージは、それいじょう 上がりません。ほかの ステージで だんを 上げて いきましょう。

じぶんの きろくを 見る（下の バーの「きろく」）

下の バーの「きろく」を おすと、これまでの あゆみが 見られます。上に レベルと れんぞく日数、その 下に 4つの ひきだしが ならびます。

きょう … きょう どれだけ 打うったか

はじめに ひらくのが「きょう」です。その日 どれだけ 打うったかが、3つの 数字で 出ます。

れんしゅうした 日の ところは、4週間ぶんの まるが ならびます。つづけて いる 日数も ここで 分かります。

にがて … キーボードの 色で にがてを 見る

「にがて」を おすと、キーボードの 絵に これまでの まちがいが 色で 出ます。どの あたりが まだ 手に なじんで いないかが、ひと目で 分かります。

上の 2つの ボタンで、「まちがえた かず」と「おぼえぐあい」を 切りかえられます。下には、手が 止まりやすい キーと、まちがえやすい ローマ字の きまりが ならびます。ここから そのまま「にがて とっくんを する」を おせます。

たからもの … バッジと ステージの ★

「たからもの」は、これまでに あつめた ものを ならべる ところです。

「ぜんぶ 見る」を おすと、24しゅるいの バッジが ぜんぶ ならびます。

バッジは、はじめて 打うった とき、まちがえずに クリアした とき、何日か つづけた とき、はやさが 上がった ときなどに もらえます。

あゆみ … さいこう記録きろくと はやさの うつりかわり

「あゆみ」には、さいこう記録きろく・はやさの グラフ・チャレンジの きろく・さいきんの れんしゅうが、上から じゅんに ならびます。

グラフを 見ると、はやさが すこしずつ 上がって いるかが 分かります。1日で かわる ものでは ないので、1週間ぐらいの ながさで 見て ください。

いちばん 下の「さいきんの れんしゅう」には、1回ぶんずつの きろくが ならびます。「もっと まえの れんしゅう」を ひらくと、40回ぶんまで さかのぼれます。

ヒントの つよさを かえる（せってい →「ヒント」）

なれて きたら、ヒントを 少しずつ 弱く します。そうすると、手もとを 見ないで 打うてるように なって いきます。

ヒントの つよさを 5つから えらぶ

下の バーの「せってい」を おすと、はじめに「ヒント」の ひきだしが ひらきます。

  1. ぜんぶ 見える … キーボードも 文字も ゆびの 色も ぜんぶ 出ます。
  2. ゆびの 色だけ … キーの 文字が 消きえます。
  3. ばしょだけ … ゆびの 色分けも 消きえます。
  4. なにも 出ない … 画面がめんの キーボードが 消きえます。
  5. じどう … おぼえぐあいに あわせて、はじめる ときに アプリが きめます。

どの つよさでも、「つぎは D を みぎの ひとさしゆびで」の ことばは 消きえません。絵が 消きえても、どの ゆびかは かならず ことばで つたわります。

こまかく きめる

「こまかく きめる」を おすと、中の 4つの スイッチを 1つずつ 切りかえられます。

ここを さわると、上の つよさは「じぶんで」に かわります。

同じ 画面がめんの 下では、手の イラストと キャラクターを 消けせます。キャラクターの しごと（かいしゃいん・シェフ・大工）を えらんで、いつも 同じ キャラクターに する ことも できます。

見た目と 音を かえる（せってい →「みため」）

まぶしい ときや、字が 小さくて 読みにくい ときは、ここで かえられます。

画面がめんの 色を かえる

「みため」の ひきだしを ひらくと、いちばん 上に 画面がめんの 色が あります。

「じどう」は、Chromebook そのものの せっていに あわせます。「くらい」を えらぶと、打うつ 画面がめんも 暗くらい 色に なります。

文字の 大きさ・おと・打うち直し

同じ ひきだしの 下に、3つの スイッチが あります。

  1. 文字を 大きくする … お題だいも 画面がめんの 文字も 大きく なります。電子黒板でんしこくばんに うつす ときにも つかえます。
  2. 打うったときの おと … 打うつ ときの 音を 消けせます。
  3. まちがえた お題だいを ひとまわりの さいごに もう1かい … ひとまわりの あとの 打うち直しを 止められます。

もっと 大きく したい ときは、ブラウザの 拡大かくだい（Ctrl と +）も つかえます。Typa は 拡大かくだいを 止めて いないので、タブレットの ピンチ操作そうさも そのまま つかえます。

「まちがえた お題だいを ひとまわりの さいごに もう1かい」は、はじめから 入って います。ひとまわりする たびに、その 中で つまずいた お題だいを もう1回だけ 出す しくみです。切ると、ひとまわりした ところで すぐ つぎの 周しゅうに すすみます。

【！】おぼえて おいて ほしい こと

  • 紙ふぶきなどの 演出えんしゅつを アプリの せっていで 止める ことは できません。端末たんまつの「視差効果しさこうかを減へらす」（アニメーションを減へらす）が 入って いれば、Typa が じどうで したがいます。
  • うごきや 音が 気に なる ときは、「ヒント」の キャラクターを 出すを 切り、ここの 打うったときの おとを 切ると、かなり へります。
  • 色が 見分けにくい ときも だいじょうぶです。まちがえた ことは、色だけで なく「ミス」の 数字と、お題だいの わくでも 分かります。Windows の ハイコントラストの せっていにも あわせて あります。

キーボードの ならびを 合わせる（せってい →「キーボード」）

打うった 文字と ちがう 字が 出る ときは、たいてい ここが 合って いません。

日本語配列にほんごはいれつ（JIS）と 英語配列えいごはいれつ（US）

「キーボード」の ひきだしを ひらくと、いちばん 上に ならびの えらびかたが あります。

キーボードの 右上に「¥」や「かな」が あれば 日本語配列にほんごはいれつ（JIS）です。「1」の 左に かな英数えいすうキーが あり、「1」は Q の ななめ 左上に あります。

ゆびの ばしょを たしかめる

同じ ひきだしの 下に、ホームポジションと ゆびの 色の 図が あります。

この 図は 見る ためだけの ものです。おしても 打うつ ことには なりません。

ローマ字ひょうで 打うちかたを たしかめる

「ローマ字ひょうを 見る」を おすと、うけつける 打うちかたの 一覧いちらんが ひらきます。

「し」は si でも shi でも 正かいです。「じゃ」は ja でも zya でも 打うてます。ならった うちかたで だいじょうぶ、と いう ことを ここで たしかめられます。

きろくを べつの 端末たんまつへ うつす・ぜんぶ けす（せってい →「データ」）

学年が かわって Chromebook が 入れかわる ときは、きろくを ファイルに して もって いけます。

【！】きろくを ファイルに 書き出す

「せってい」→「データ」→「書き出し・読みこみ」と おします。

書き出しの 手順てじゅん:

  1. 「ファイルに 書き出す」を おします。できた ファイルは「ダウンロード」に 入ります。
  2. ダウンロードが つかえない ときは「がめんに 出す」を おします。文字に なって 出るので、ぜんぶ えらんで コピーします。
  3. できた ファイルを、USB メモリや クラウドで 新しい 端末たんまつに うつします。

【！】おぼえて おいて ほしい こと

  • できる ファイルは その 端末たんまつの 中に できます。インターネットには 出ません。
  • 名前や 出席しゅっせきばんごうは 入って いません。
  • 書き出しも 読みこみも、Tab キーと エンターキーだけで できます。マウスは いりません。

書き出した ファイルを 読みこむ

新しい 端末たんまつで Typa を ひらき、同じ 画面がめんの「ファイルを えらぶ」から 書き出した ファイルを えらびます。読みこむ 前に、中身なかみ（れんしゅうの 回数・★の 数・けいけんち・さいごの 日）が 出るので、たしかめてから すすめて ください。

読みこむと、いまの きろくは 消きえて、ファイルの きろくに なります。2つの きろくは まざりません。もとには もどせないので、読みこむ 前に いまの きろくを 書き出して おくと あんしんです。

【！！】きろくを ぜんぶ けす

「せってい」→「データ」の いちばん 下に「きろくを ぜんぶ けす」が あります。

消きえるのは、★・れんしゅうの きろく・レベルと バッジ・チャレンジの きろくです。ヒントの つよさや キーボードの ならびなどの せっていは のこります。

一度いちど 消けすと もとには もどせません。とっておきたい ときは、けす 前に かならず ファイルに 書き出して ください。

うまく いかない ときは

こまった ときは、まず ここを 見て ください。おおい ものから ならべて あります。

キーを おしても すすまない とき

日本語入力（かな入力）に なって いないか たしかめて ください。かな英数えいすうキー（「1」の 左）か 英数えいすうキー（スペースの 左）を 1回 おしてから 打うちます。

打うった 文字と ちがう 字が 出る ときは、せってい →「キーボード」の ならびが 端末たんまつと 合って いません。日本語配列にほんごはいれつと 英語配列えいごはいれつを 合わせて ください。

画面がめんが まっしろの まま、または 出ない とき

いちど アプリを ぜんぶ とじて、ひらき直して ください。Typa は 外の サイトを 1つも 読まないので、学校の フィルタリングで 止まる ことは ありません。

「インターネットに つながって いません」と 出た ときは、まだ 一度いちども アプリを 取とれて いない 端末たんまつです。つながる ところで いちど ひらいて ください。

「あたらしい ばんが あります」と 出た とき

画面がめんに 帯おびが 出たら「さいしんに する」を おして ください。おすまで 切りかわりません。打うって いる とちゅうに 画面がめんが 消きえない ように して あります。

きろくが きえて しまった とき

ブラウザの データを 消けすと、きろくも いっしょに 消きえます。iPad や iPhone の Safari は、7日 ひらかないと 消きえる ことが あります。ホーム画面がめんに 追加ついかして おくと 消きえにくく なります。

書き出した ファイルが あれば、読みこんで もどせます。

べつの 人の きろくが 出て いる とき

同じ 端末たんまつを みんなで つかって います。Typa は 端末たんまつごとに 1つの きろくを もつので、人ごとに 分ける ときは ブラウザの プロフィールを 分けて ください。

それでも 直らない とき

まず、この アプリを 教えて くれた 先生か、じょうほうの 先生に 聞いて ください。いちばん 早く かいけつします。

それでも 分からない ときは、この ページの いちばん 下に ある 問とい合わせ先から しらせて ください。

先生へ（クラスで つかう ときと、印刷いんさつ）

ここは 先生むけの ところです。ふだん つかう ぶんには、読まなくて だいじょうぶです。

はじめる まえの じゅんび

  1. さいしょの 1回だけ、インターネットに つないで ひらいて ください。その ときに アプリ一式いっしきが 端末たんまつに 入り、つぎからは 圏外けんがいでも つかえます。
  2. 40人が 一斉いっせいに ひらいても だいじょうぶです。通信つうしんを しない アプリなので、校内 Wi-Fi の こみぐあいに 左右されません。
  3. ヒントの つよさは 児童じどうごとに ちがって かまいません。せっていは 端末たんまつに のこるので、毎回 合わせ直す ひつようは ありません。

きろくが のこる ばしょ

れんしゅうの きろみは、その 端末たんまつの ブラウザの 中だけに たまります。名前・出席番号しゅっせきばんごう・メールアドレスは 一切 あつかいません。通信つうしんを する コードが そもそも 入って いません。

端末たんまつを 入れかえる ときは、上の「きろくを べつの 端末たんまつへ うつす」の 手順てじゅんで ファイルに して ください。学期がっきの 区切くぎりで 書き出して おくと あんしんです。

ローマ字ひょうを 紙に して 配くばる

Typa は 印刷いんさつして つかう アプリでは ありませんが、ローマ字ひょうは 紙に して 配くばれます。

印刷いんさつの 手順てじゅん:

  1. せってい →「キーボード」→「ローマ字ひょうを 見る」を ひらきます。
  2. Ctrl と P（Mac は ⌘ と P）を おします。
  3. 下の バーと ボタンは 印刷いんさつでは 自動じどうで 消きえます。表ひょうが ページを またいで 割われて いないかを たしかめて ください。
  4. 用紙は A4 たて、よゆう 12mm が はじめの せっていです。

【！】おぼえて おいて ほしい こと

  • 紙面しめんとして きれいに 整ととのえる 設計せっけいは まだ して いません。気に なる ときは、いったん PDF に 出して 見て ください。
  • 児童じどうに 配くばる ときは、ならって いない 打うちかたも のって いる ことを ひとこと 伝つたえて おくと まよいません。

学校で使うときは

ここは giga-school.com が アプリの設定から組み立てています。マニュアルの書き手が手で書いたものではないので、 アプリが変われば、ここも変わります。
