# 品質ゲートのフォーク9本 — 実測と、どうするか

`scripts/lib/giga-v5-checks.mjs` は正本（`standards/lib/`）と同じ場所・同じ名前で
置かれているのに、**中身が別物**のリポジトリが9本ある。
2026-08-22 に実測した結果と、扱いの判断をここに残す。

## 扱いを決めた（2026-08-22）

当初は `check-drift.mjs` の「未登録」の報告をあえて黙らせずにいた。消すと
「移行がまだ」という事実まで見えなくなる、と考えたためである。

**それをやめて、9本すべてを `unmanaged` に宣言した。** 理由は2つ。

1. 警告を鳴らしっぱなしにしても、事実は伝わらない。「未登録が9件」と出るだけで、
   なぜ移行しないのか・危険なのかどうかは読めない。`unmanaged` の `reason` には
   何行でも書けるので、そこに実測と判断を残すほうが確実に伝わる。
2. 鳴りっぱなしの警告は読まれなくなる。10件目の本物の未登録が紛れこんでも
   気づけない。宣言を済ませて `--strict` を付けられる状態にしておけば、
   新しい未登録は必ず赤になる。

つまり、この文書と各リポジトリの `reason` が「警告への答え」であって、
警告そのものが答えではなかった。

## 実測

正本は 965 行・38 検査。フォークは 275〜584 行で、**検査IDの体系からして違う**
（正本 `A_LICENSE` に対し quarto / mirai-compass は `A1_LICENSE`）。
`quality.config.json` の書式も違う（quarto は `appVersion` / `swSource` /
`knownDeviations` という別世代）。**コピーし直せば済む話ではない。**

## 判断

### app_launcher — 移行しない

PWA ではなく Chrome 拡張（`background.js` / `content.js` / `popup.html` /
`manifest.json`）。PWA 向けの検査を当てるのは誤り。275 行のゲートはこの
リポジトリに合っている。**フォークではなく、種類が違う。**

### 残る8本 — 段取り①は済み、②は急がない

移行は2段に分けられる。

1. **版ずれの検出だけ入れる**（小さい・すぐ効く）
   `standards/sw/build-sw-static.mjs` か `build-sw-vite.mjs` を配り、
   `sw.js` の版行に目印を付け、ゲートに `--check` を足す。
   ゲート本体には触らない。
2. **ゲートを正本へ寄せる**（大きい）
   検査IDの体系と `quality.config.json` の書式が変わるので、
   設定の作り直しと全項目の再確認が要る。1本ずつ。

**① は 2026-08-22 に8本すべてで完了した。** いちばん高い危険——
「配信物を変えたのに版が据え置きのまま緑になる」——はどのリポジトリからも消えた。

② は急がない。いま困っていることは無く、1本あたり全項目の再確認が要る。
ほかの作業のついでに、1本ずつで構わない。

## ② の4本目 — quarto（2026-08-23 に完了）

はじめて**別の作りの PWA**に当てた。ここまでの3本は「public/sw.js を自分で書く」
形だったが、quarto は vite-plugin-pwa の injectManifest を使う。
manifest も先読み一覧もビルド時に作られるので、**原文をいくら読んでも
真偽が決まらない**検査が出てくる。

### 分からないものは「分からない」と言わせる

正本には、宣言だけを見て中身は各リポジトリに任せる、という置き方をした。

- `E_SW_PRECACHE_OFFLINE` は `self.__WB_MANIFEST` を見つけたら、
  `sw-build.config.json` の `precacheManagedByPlugin: true` があるかだけを見る。
  **宣言が無ければ落とす**（黙って素通りさせない）
- 実際に offline.html が入ったかは、quarto 側の `E10_OFFLINE_PRECACHED` が
  ビルド結果 `dist/sw.js` を読んで確かめる
- ビルドしていなければ `BUILD_PRESENT` が落ちる。dist を見る検査が
  丸ごと効かないまま緑になるのを防ぐ

#48 で `__PRECACHE_URLS__` 型に入れた考え方と同じである。
**「原文では決まらない」ことを認めたうえで、決まる場所に検査を置く。**

### また正本の欠陥が2件出た。しかも片方は重い

- **#54**: 版の目印の形を1通りしか知らなかった。正本の build-sw-vite.mjs は
  はじめから2通り（行末コメント形と、値そのものが `'__APP_VERSION__'` の形）に
  対応していたのに、ゲートだけが前者しか見ていなかった。**配る側と検査する側で
  食い違っていた**わけで、正しく自動生成しているリポジトリを落としていた。
- **#55**: `index.html` の説明文に `<style>` と書いてあると、そこから本物の
  `</style>` までが「CSS」として読まれていた。quarto では 3,164 文字の説明文が
  混ざり、**本物の CSS から `prefers-reduced-motion` を丸ごと消しても
  `D_REDUCED_MOTION` が通った**。同じ形の見のがしは `D_SAFE_AREA` /
  `D_FLUID_TYPE` / `D_FORCED_COLORS` にもかかる。
  検査が「書いてある言葉」で満たされてはいけない。

4本やって、正本の欠陥が出たのは 1本目・3本目・4本目。**毎回、変異表を
書き直しているときに出ている。** 移行の値打ちは、そこにいちばんある。

## ② の6本目 — schoolplan_editor（2026-08-23 に完了）

Vite 型ではない。**GAS のアプリを iframe で開くだけのシェル**を GitHub Pages の
`docs/` から配る、この艦隊でここだけの作りである。しかも**公開ページが2枚**ある

### 移行の前に、公開ページの本物の不足が4件出た

正本を当てたら `docs/index.html` で4件落ちた。**どれも検査が厳しすぎるのではなく、
実際に困る側の欠け**だったので、ゲートを緩めずページを直した。

| 落ちた検査 | 実際に起きること |
|---|---|
| CSP が無い | 差し込まれたスクリプトを止める手立てが無い |
| インライン script 400行 | CSP を入れるなら `'unsafe-inline'` が要り、CSP の意味がほぼ消える |
| `prefers-reduced-motion` 無し | 動きに弱い子の設定を無視して回り続ける |
| `clamp()` が1か所も無い | 電子黒板と手元の端末で字が読みにくい |

400 行のインライン script は `docs/app-url.js` に出した。中身は変えていない
（インデントを外しただけ、と diff で示せる）。**出したら `SHELL_ASSETS` に足すこと。**
足さないと圏外で HTML だけ控えから出て、中身が動かない。

`frame-src` には `script.google.com` と `*.googleusercontent.com` の両方が要る
（GAS の `/exec` は開くと転送される。片方だけだと画面が真っ白になる）。
`frame-ancestors` は `<meta>` では無視されるので書かない——**書けないことを
コメントに残す**。GitHub Pages では HTTP ヘッダーを足せない。

Chromium で実際に開き、CSP 違反ゼロ・スクリプトの実行・iframe の src 設定を
実測して確かめた。

### また正本の欠陥が2件出た。しかも片方は「黙って通す」形

- **#59**: `E_CNAME` が直下の `CNAME` しか見ていなかった。このリポジトリの
  `docs/CNAME` は見つけられず、**「独自ドメインをつかっていません」と
  黙って通していた。** 落ちるのではなく通るので、いちばん気づけない形である。

同じ形の見のがしを `scripts/lib/project-quality.mjs` にも見つけた。
`extractScriptBlocks` が HTML コメントの中の `<script>` を本物と読んでいて、
CSP の注意書きを書いたら構文エラーになった。**#55 とまったく同じ欠陥**が、
