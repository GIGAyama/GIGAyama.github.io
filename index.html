このサイトのアプリに共通すること

  • ブラウザだけで動く

    アドレスを開けばその場で使えます。端末へのインストールや、管理者による配布の作業は要りません。

  • 費用はかからない

    すべて無償で公開しています。利用登録や課金の仕組みはありません。

  • 中身を確かめられる

    ソースコードは GitHub で公開しています。何をしているアプリなのか、導入前に読んで確かめられます。

ABOUT

このサイトについて

アドレスの決まり

各アプリは アプリ名.giga-school.com のアドレスで公開しています。このページはその入口です。

プライバシーポリシーと利用規約

アプリごとに内容が異なるため、それぞれのアプリの中に置いています。カードの「プライバシー」「利用規約」から開けます。

不具合の報告・要望

各アプリの GitHub リポジトリの Issues か、下のメールアドレスへお寄せください。

個人がひとりで開発・運用しているサイトです。学校や教育委員会の公式なものではありません。

学校でお使いになる場合は、各設置者の定めるルールに従って、内容をご確認のうえご判断ください。 アプリによっては Google アカウントでの認可（ログイン）が必要なものがあります。
