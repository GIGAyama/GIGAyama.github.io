GIGA school

小学校の教員が、日々の授業と校務のためにつくっている Web アプリを公開しています。

いずれもブラウザだけで動く無償のツールです。インストールは不要で、ソースコードはすべて GitHub で公開しています。

  • どこでも時間タイマー（Blackboard_Timer）
