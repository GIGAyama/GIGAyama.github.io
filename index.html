授業と校務でつくった道具を、そのまま公開しています。

日々の授業や学級の仕事で「これがあれば」と思ったものを形にした Web アプリです。 ブラウザで開けばそのまま動き、費用はかかりません。ソースコードもすべて公開しています。

このサイトのアプリに共通すること

  • ブラウザだけで動く

    アドレスを開けばその場で使えます。端末へのインストールや、管理者による配布の作業は要りません。

  • 費用はかからない

    すべて無償で公開しています。利用登録や課金の仕組みはありません。

  • 中身を確かめられる

    ソースコードは GitHub で公開しています。何をしているアプリなのか、導入前に読んで確かめられます。

公開中のアプリ（38 本）

学年（どの子が使えるか）と教科・分野（何の時間に使うか）と つかいかた（学びのどの場面を助けるか）で絞り込めます。3 つは掛け合わせられます。 アプリ名や説明のことばでも検索できます。 学年を選ぶと、先生だけが使う道具（週案エディタ・宿題ポストなど 7 本）は外れます。 各アプリのプライバシーポリシーと利用規約は、それぞれのアプリの中に置いています。 校内のフィルタリングで許可するアドレスは1 枚にまとめてあります（印刷して情報担当の先生にお渡しください）。 紹介の記事だけを読むこともできます。
