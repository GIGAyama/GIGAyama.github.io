GIGAyama

小学校の教員が、日々の授業と校務のためにつくっている Web アプリを公開しています。

いずれもブラウザで動く無償のツールです。ソースコードは GitHub で公開しています。

公開中のアプリ

  • 週案エディタ（School Plan Note）

    週案（週間指導計画）の作成、時数管理、タスク管理、学級通信づくりを 1 つの画面にまとめた、教員向けの校務支援アプリです。データは先生ご自身の Google スプレッドシートに保存されます。

このほかのアプリは GitHub のリポジトリ一覧からご覧いただけます。
